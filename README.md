# Beam Designer

Beam Designer is a Python desktop app for analyzing steel and lumber beams. It
calculates reactions, shear, moment, and deflection, checks bending and
deflection limits, and can save/open designs or export CSV and calculation-sheet
PDF reports.

## Requirements

- Python 3 with Tkinter. No third-party Python packages are required.
- If Tkinter is missing on Debian/Ubuntu, install it with `sudo apt install python3-tk`.

## Run

```bash
python3 app.py
```
